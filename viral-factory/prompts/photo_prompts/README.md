# Промпты для генерации картинок к постам

Здесь две отдельные папки:

1. **`serious/` (Серьёзные посты)**:
   - **СТРОГО БЕЗ МАСКОТА!**
   - Реалистичная профессиональная съёмка в автосервисе: механик, подъёмник, диагностика, приборы, узлы автомобиля.
   - Сгенерированные фото складывай в: **`D:\zcode ворк\ai-images\serious\`** (формат `.jpg` или `.png`).

2. **`funny/` (Юмористические посты)**:
   - **С МАСКОТОМ!**
   - Яркий 3D мультяшный рендер в стиле Pixar: машинка AVTOHABR с выразительными глазами на лобовом стекле (фары без глаз!).
   - Сгенерированные фото складывай в: **`D:\zcode ворк\ai-images\funny\`** (формат `.jpg` или `.png`).

> ⚠️ **Важно**: Сохраняй файлы только как `.jpg` или `.png` (не `.webp`!).
