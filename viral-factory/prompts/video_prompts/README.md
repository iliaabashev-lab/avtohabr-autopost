# Промпты для генерации коротких видео (9:16)

## Как генерировать:
1. Открой любой файл из этой папки (например, `008_video.md`).
2. Скопируй блок **«ПРОМПТ ДЛЯ AI STUDIO»**.
3. Вставь в **Google AI Studio (модель Omni 1.1 Flash)**:
   - Формат: **9:16** (вертикальный)
   - Длительность: **10 секунд**
4. Скачай готовый ролик `.mp4`.
5. Сохрани в папку **`D:\zcode ворк\ai-videos\`** под именем номера истории (например, `008.mp4`).

Ролики генерируются уже с речью маскота и звуковыми эффектами — фабрика сама выложит их в ВК Клипы и Telegram!
