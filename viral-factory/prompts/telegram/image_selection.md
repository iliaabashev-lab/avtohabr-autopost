# PROMPT: TELEGRAM IMAGE SELECTION & MATCHING RULES

## 1. БАЛАНС ТОНАЛЬНОСТИ В СОЦСЕТЯХ
- Посты генерируются в строгом соотношении: **3 серьёзных поста на 2 шуточных** (на каждые 5 постов).
- Ритм публикаций: `[Серьёзный, Серьёзный, Шуточный, Серьёзный, Шуточный]`.

## 2. ТЕМАТИЧЕСКИЙ ПОДБОР КАРТИНОК (ПО СМЫСЛУ ПОСТА)
Изображение подбирается строго по смыслу поломки или услуги:
- Пост про тормоза -> фото колодок, тормозного диска, замера износа.
- Пост про диагностику / чек -> фото диагностического сканера, приборной панели.
- Пост про шиномонтаж -> фото балансировочного станка, протектора шины.
- Пост про аккумулятор -> фото тестера АКБ, клемм под капотом.
- Пост про фары -> фото полировки фар, регулировки светового пучка.

## 3. СТРОГАЯ ИЗОЛЯЦИЯ ПО ПАПКАМ
- Для серьёзных постов (`serious`): берутся фото только из папки `ai-images/serious/` или скриншоты сервиса. **СТРОГО БЕЗ МАСКОТА**.
- Для шуточных постов (`funny`): берутся 3D-рендеры только из папки `ai-images/funny/` **С МАСКОТОМ**.
- Форматы: **строго `.jpg` или `.png`**. Формат `.webp` заблокирован для `sendPhoto`.
- Если подходящее фото отсутствует, публикатор активирует безопасный режим `allow_text_fallback: true` (отправляет качественный текст без картинки, не роняя публикатор).
