# Как выкладывать ролики AVTOHABR без ассистента

## Откуда берутся ролики
1. Фабрика каждый день в 06:00 МСК создаёт 5 новых историй: `viral-factory/stories/NNN/story.json` (текст) + `prompts.md` (промпт для видео — машинка ГОВОРИТ реплики, глаза только на лобовом стекле).
2. Владелец генерирует клипы в **Google AI Studio (Omni 1.1 Flash)** по промптам и складывает готовые mp4 в папку `D:\zcode ворк\ai-videos\` с именем `NNN.mp4` (например `013.mp4`).
3. Ролики из AI Studio **уже со звуком и речью** — фабрика их НЕ озвучивает и НЕ рендерит: файл публикуется как есть (ВК — автоматом, YouTube — автоматом после аудита).
4. Готовые ролики: https://github.com/iliaabashev-lab/avtohabr/tree/factory-media/media/story — файлы `NNN.mp4` (9:16), рядом `jobs-ДАТА.json` с готовыми title и caption.

## Как сделать клип в Google AI Studio (10 с)
1. Открой промпт истории: `viral-factory/stories/NNN/prompts.md` → блок **«Видео (одним промптом)»**.
2. Вставь его целиком в AI Studio (Omni 1.1 Flash), формат **9:16**, длительность **10 секунд**.
3. Скачай результат и сохрани в папку **`D:\zcode ворк\ai-videos\`** как `NNN.mp4` (например `013.mp4`).
4. Если модель развалила сцену — перегенерируй тот же промпт ещё раз (каждая попытка новая).
5. В промпте машинка произносит реплики вслух (весь текст уже вшит в промпт). Если реплика прозвучала криво — просто перегенерируй.
6. Пачкой на 2 недели вперёд можно генерить заранее: промпты уже в `stories/001, 008–072`, фабрика опубликовывает по 5 в день.

## Когда выкладывать (МСК)
5 роликов в день: **09:00, 12:00, 15:00, 18:00, 21:00**. Один ролик можно выкладывать на всех площадках в одно время. ВК публикует сам, YouTube — сам (когда настроим API), остальное вручную.

## Площадки

### ВК Клипы (vk.com/club242845245) — автоматом
Фабрика выкладывает сама через API. Если ролика нет в клипах — «Создать» → «Клип» → файл, описание из `caption`, публикуй от имени сообщества.

### YouTube Shorts — автоматом после настройки (пока вручную)
Фабрика загружает Shorts сама (секреты `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`). Одноразовая настройка: см. шаги в начале `viral-factory/scripts/oauth-setup.mjs` и запусти `node oauth-setup.mjs <CLIENT_ID> <CLIENT_SECRET>` на своём ПК.
⚠️ Пока новый проект Google Cloud не пройдёт бесплатный аудит (форма «YouTube API Services – Audit and Quota Extension» в Google Cloud Console), ролики от API блокируются как приватные — до аудита поставь секрет `YT_PRIVACY=private`, после аудита убери (по умолчанию публикуются открыто).
Ручная загрузка (пока автомат не настроен): «Создать» → «Загрузить видео», **название:** `title` + ` #shorts` (до 100 символов), **описание:** `caption`, «Не для детей» → Далее ×3 → публикация/расписание.

### Instagram Reels — ведёшь вручную
- «+» → Reels → выбрать ролик → **без обрезки** (формат уже 9:16).
- **Подпись:** `caption`, хэштегов не больше 5. Обложка: кадр из первой секунды.

### Telegram-канал — автоматом (09:00, 13:00, 17:00 МСК)
- 3 поста в день по Московскому времени (текстовые и с проверенными фото).
- Секреты в GitHub Actions / .env: `TG_BOT_TOKEN` (токен бота от @BotFather, бот должен быть админом канала) и `TG_CHAT_ID` (`@channel` или `-100...`).
- Проверка состояния очереди: `node viral-factory/scripts/telegram-post.mjs status`.
- Безопасная симуляция без отправки: `node viral-factory/scripts/telegram-post.mjs dry-run`.
- Повтор сбойного поста: `node viral-factory/scripts/telegram-post.mjs retry <post_id>`.

### Threads (threads.com) — автоматом
Бот публикует сам по расписанию 8:00–17:00 МСК. Ритм: 3 текстовых поста → пост с картинкой → пост с видео.

## Правила описаний
- Первая строка = хук (как в `title`), эмодзи 1–2.
- Без канцелярита и фраз «важно отметить», «уникальный», без выдуманных цифр.
- В конце: «Водителям бесплатно / сервисам 14 дней бесплатно 👉 app.avtohabr.ru».
- Никогда не используй старое название AVTOSERV.
- Отвечай на комментарии коротко, 5–6 слов, по смыслу и с юмором; ставь лайк.

## Что фабрика делает сама каждый день в 06:00 МСК
- **ВК, текстовые посты:** 5 новых в день, публикуются сами от имени сообщества (09–21 МСК).
- **Промпты видео:** 5 новых историй в день (`out/ДАТА/flow-prompts.md` + `stories/NNN/prompts.md`). История без `video.mp4` и без кадров считается ждущей; если ждущих больше 15, новые промпты не появляются, пока не загрузишь клипы.
- **Монтаж:** истории с загруженным `video.mp4` (или кадрами `1…5.jpg`) фабрика озвучивает, монтирует с рекламной вставкой и складывает в ветку `factory-media/media/story/`, затем публикует в ВК.
- **vc.ru:** `out/ДАТА/vc.md`, по понедельникам. Публикуй вручную.
- **DRIVE2:** `out/ДАТА/drive2.md`, раз в 3 дня. Публикуй вручную.
- **Threads:** черновики и публикация автоматом.
